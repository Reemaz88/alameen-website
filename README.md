# موقع ماهر وهاشم الصوفي للاستشارات والخدمات العامة

موقع تعريفي من صفحة واحدة بالعربية والإنجليزية، يعرض خدمات المكتب: المحاسبة، برنامج الأمين، أنظمة نقاط البيع، التدريب، وغيرها. يفتح الموقع بالعربية في الزيارة الأولى، ويمكن للزائر التبديل إلى الإنجليزية.

الموقع مبني بـ [Vite](https://vitejs.dev) و JavaScript بسيط دون أي إطار عمل.

## التشغيل على جهازك

يحتاج [Node.js](https://nodejs.org) الإصدار 18 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادةً `http://localhost:5173`). أي تعديل تحفظه يظهر فورًا في المتصفح.

> لا تفتح ملف `index.html` مباشرة بالنقر عليه، ستظهر صفحة بيضاء. استخدم دائمًا `npm run dev`.

## البناء

```bash
npm run build
npm run preview
```

الأمر الأول يجهّز النسخة النهائية في مجلد `dist`، والثاني يعرضها للتأكد منها قبل النشر.

## النشر على GitHub Pages

النشر تلقائي. عند كل `git push` إلى الفرع `main` يقوم ملف `.github/workflows/pages.yml` ببناء الموقع ونشره خلال دقيقة إلى ثلاث دقائق. يمكنك متابعة حالة النشر من تبويب **Actions** في المستودع.

يجب أن يكون **Settings ← Pages ← Source** مضبوطًا على **GitHub Actions**. مجلدا `dist` و `node_modules` لا يُرفعان إلى GitHub.

## أين أعدّل؟

| ماذا تريد أن تغيّر | الملف |
|---|---|
| كل محتوى الموقع: الاسم، الشرائح، الخدمات، من نحن، الأرقام، العنوان، الخريطة، روابط التواصل الاجتماعي | `src/content.js` |
| نصوص الأزرار والعناوين الثابتة ورسائل واتساب الجاهزة | `src/translations.js` |
| الألوان والتصميم | `src/style.css` (المتغيرات في أعلى الملف) |
| طريقة عرض الأقسام | `src/main.js` |
| الشعارات | `public/images/logo/` |
| الصور | `public/images/` |

كل نص في `src/content.js` له نسخة عربية `ar` وأخرى إنجليزية `en`، فعدّل الاثنتين معًا. اكتب مسار الصورة بدون شرطة في البداية، مثل `images/pos-counter.jpg`.

## نموذج التواصل

ليعمل النموذج، أنشئ مفتاحًا مجانيًا من [web3forms.com](https://web3forms.com) وضعه في `web3formsKey` داخل `src/content.js`. ستصل الرسائل إلى البريد المسجّل في Web3Forms.
